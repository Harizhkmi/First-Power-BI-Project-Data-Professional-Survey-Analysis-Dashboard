# My First Power BI Project: Data Professional Survey Analysis Dashboard

## 📊 Project Overview

This is my first Power BI dashboard project, where I explore and analyze survey data from data professionals around the world. The goal of this project is to practice data visualization, data analysis, and dashboard development using Microsoft Power BI.

## 🎯 Project Objectives

- Analyze the demographics of survey respondents.
- Compare average salaries across different data-related job titles.
- Explore respondents' favorite programming languages.
- Understand work-life balance and salary satisfaction.
- Investigate respondents' experiences entering the data industry.

## 🛠️ Tools Used

- **Microsoft Power BI** — Data visualization and dashboard development.
- **Power Query** — Data cleaning and transformation, where applicable.
- **DAX** — Calculations and aggregations, where applicable.

## 📈 Dashboard Features

The dashboard includes the following visualizations:

- **Total Survey Takers** — Displays the number of survey respondents.
- **Average Age** — Shows the average age of respondents.
- **Average Salary by Job Title** — Compares salaries across data-related professions.
- **Favorite Programming Language** — Shows the most popular programming languages among respondents.
- **Respondents by Country** — Visualizes the geographical distribution of participants.
- **Work-Life Balance and Salary Satisfaction** — Displays survey ratings for work-life balance and salary satisfaction.
- **Difficulty Breaking into Data** — Explores how respondents perceive the difficulty of entering the data industry.
